# 🛡️ PhishGuard — AI-Powered Phishing URL Detection

🔗 **Live Demo:** https://phishguard-shuvtblpuj7wrbbzcora7e.streamlit.app/

PhishGuard is an AI-powered phishing URL detection system designed to analyze suspicious URLs and identify potential phishing threats using machine learning and rule-based cybersecurity analysis.

## 🚀 Features

- 🤖 Machine Learning-based URL classification
- 🔍 Rule-based security analysis
- 📊 Combined risk scoring
- 🧠 URL feature analysis
- 🌐 Domain intelligence
- 💾 Scan history
- 📈 Security dashboard
